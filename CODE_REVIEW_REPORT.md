## Архитектура и фактический охват

Java 21, Gradle 8.12.1, Architectury. Common содержит public thaumcraft.api, server gameplay, recipes, NBT/components/SavedData, C2S/S2C, menus и клиент. Fabric/NeoForge подключают lifecycle, mixins, fluid/platform hooks. Compat EMI/JEI/Jade компилируются в loader source sets, example-addon проверяет внешний API. Состояние — native world/player storage и локальные properties; SQL/веб-сессий здесь нет.

Входы: loader initialization, native server tick/entity/block events, C2S receivers, menu clicks, item use, datapack codecs и addon callbacks. Основные пути прослежены через оплату/перенос предметов, recipe matching, права, persistence и client presentation. Проверялись доверенные серверные данные отдельно от player packets; отдельное внимание синхронной реентерабельности native/mod callbacks. Аутентификация сервера остаётся native Minecraft, не разрабатывалась новая схема пользователей.

Исходный инвентарь поддерживаемого Java: 1626 файлов (включая compiled compat subtype regression). Для всех есть запись статического просмотра: 480 в первой итерации +1146 в шести разделах второго прохода. Это НЕ заявление о полном построчном или runtime покрытии: часть просмотра выполнена по control flow, семь render/model файлов содержат частично просмотренные большие геометрические литералы. Дополнительно закрыты все 16 явно отмеченных ранних partials: 7 Java (1834 строки) и 9 build/Python (3147 строк). Production/compat/example входят в этот инвентарь; новые NPC helpers/mixins просмотрены отдельно; построчный аудит всех исторических test/client-automation helpers не заявляется. ## Совместимость и оставшиеся риски

Ограничение NeoForge взято из [AGENTS.md:8](/workspace/Thaumcraft-1.21.1/AGENTS.md:8): «Do not develop or run NeoForge builds/tests in parallel with the remaining content work». Поэтому новые runtime/build результаты относятся к Fabric; Neo adapters/AT проверены только статически, перечисленный отдельный runtime defect оставлен без непроверенного изменения. Во время ревью пользовательский запрет commit/push имел приоритет над прежними указаниями AGENTS о main. Последующая отдельная команда пользователя «запуш» разрешила коммит и push в main.

KeyLink(String,int) и старый codec сохранены, добавлен key_scope(dimension,owner). Старые unscoped keys ничего не теряют физически, но не могут автоматически доказать право на защиту: current owner должен явно перепривязать ключ к нужному замку. Existing access lists не переписываются. Также намеренно устранён исходный TC4 short-array crash для допустимых primal addon аспектов; first-pair quirks более длинных массивов сохранены. Это намеренное исправление исходного authority дефекта TC4.

DeferredItemDrops пишет V5 с typed grate output и читает V1–4. Форматы остальных владельцев не мигрируются. Возврат на старую версию с непустой V5 очередью не подтверждён; использовать backup либо дождаться её обработки. Надёжность native persistence не выдаётся за атомарность при аварийном выключении процесса между всеми файлами Minecraft.

Публичные строгие constructors recipes сохранены. Native пустой tag остаётся нематчащимся, oversized/unrepresentable vis recipe отклоняется. Нестандартный прямой grate API stack>99 отклоняется как не сохраняемый native ItemEntity codec; обычная hopper граница64 не изменена. Native permissions/world border усиливают AOE и example focus; claim-моды с собственной политикой требуют отдельной интеграционной проверки.

Уже потерянные до исправления NPC профессии автоматически не угадываются и не восстанавливаются: прежний тип уже отсутствует в их данных. Новые NPC и NPC с сохранившейся профессией защищены. Отложенный40tick restock intent остаётся transient, как в исходном1.7.10 поведении. Ресток проверен actual paid cycle для банкира; отдельный полный paid cycle wizard не прогонялся. Forge candidate-pool расширение списка и эквивалентность старых metadata families при сравнении разных flattened IDs требуют отдельной parity проверки; фикс сохраняет текущую полную таблицу и не добавляет новые политики торговли.
