# Thaumcraft 4.2 FOREVA — Minecraft 1.21.1

Локальная ветка `port/minecraft-1.21.1` переносит Thaumcraft 4.2.3.5 на Java 21, Architectury, Fabric и NeoForge. Это начальный рабочий этап переноса, а не полный игровой мод. Старый код Forge 1.12.2 сохранён в `src/` как справочник и не входит в новую сборку.

**Текущий приоритет — Fabric-first (решение пользователя16.10).** Сначала полный
игровой контент на Fabric; NeoForge до этого на паузе. Его существующий модуль
сохранён, но новые Fabric-срезы не считаются проверенными на NeoForge.

## Что уже работает

- Реестры предметов, блоков, block entities и компонентов данных 1.21.1.
- 48 оригинальных аспектов и данные 201 исследования. Каталог ещё не означает полную механику исследований или крафт.
- Знания игрока: исследованные объекты, очки аспектов, исследования и warp; сохранение, восстановление и синхронизация с сервера.
- Обычный таумономикон: создание жезлом из книжной полки, карта категорий и исследований, чтение открытых текстовых страниц с исходными иллюстрациями. Скрытые исследования, подсказки и вкладка Внешних Земель учитывают оригинальные условия видимости.
- Вторичные исследования покупаются в книге за исходные очки аспектов при обычной сложности: сервер проверяет условия и весь баланс, списывает точную стоимость и синхронизирует результат. Повторный запрос не расходует очки снова.
- Первичные записки выдаются из книги за одну бумагу и порцию чернил: сервер проверяет условия и существующую записку, сохраняет сетку и обрабатывает полный инвентарь. Есть исходный генератор и проверка решения; готовое открытие изучается сервером один раз. Чернильница на100 имеет исходные рецепты создания/заправки.
- Исследовательский стол: крафт/конверсия пары, общий инвентарь и сохранение; редактирование/решение записок, объединение аспектов с открытиями и бонусы окружения. Открытие можно вынуть и изучить. Копирование ещё не включено.
- Таумометр: серверное сканирование известных блоков, выпавших предметов и узлов после 20 тиков удержания цели. Сканирование существ и подсказки исследований пока не перенесены.
- Природные infused ores, киноварь и янтарь: генерация, добыча осколков, Silk/Fortune/XP и переплавка. Из природных осколков можно изготовить таумометр.
- Деревянный жезл с железными наконечниками: 25 vis на первичный аспект; природные обычные узлы, зарядка, восстановление vis и потеря истощённых аспектов. Особые типы узлов ещё не перенесены.
- Базовый стабилизатор обычного узла: настоящий крафт, защита от обоих направлений поглощения соседних узлов, исходная задержка редстоун-переключения и удвоенный интервал восстановления. Игрок по-прежнему может заряжать жезл. Раскрывающиеся поршни и прозрачная оболочка отображаются; VisNet/преобразователь/особые узлы пока не реализованы.
- Магический верстак: конверсия базового стола жезлом, сохраняемая сетка/жезл, обычный и магический крафт с серверной проверкой vis. Первые рецепты — зачарованная ткань и банка; в книге отображаются страницы уже действующих рецептов.
- Банка на 64 единицы одного аспекта, пузырьки по 8 единиц; содержимое сохраняется в выпавшей банке.
- Пустотная банка: настоящий крафт, всасывание и уничтожение излишка при заполненных64; ручная фиала по-прежнему требует8 свободных мест. Заполненные банки сохраняют состав/бирку при переносе, имеют содержимое в API и подсказке предмета.
- Трубы эссенции: крафт из капли ртути, suction и перенос по единице в банки сверху; соединения закрываются и открываются жезлом. Клапан управляется рукой и фронтами редстоун-сигнала, резонатор показывает содержимое и всасывание. Работают фильтр с оплаченной биркой, ограничитель, направленная труба и буфер на8смешанных единиц. Алхимическая конструкция — обычный компонент-блок; центрифуга превращает единицу сложного аспекта в один случайный непосредственный компонент, с исходным таймером и редстоун-паузой.
- Кристаллизатор: реальный медленный режим, редстоун-пауза, кристалл одного аспекта за единицу эссенции; вывод в проверенные обычные сундук/воронку/печь либо физически в мир. Типизированные кристаллы сохраняются, имеют исходные аспекты/цвет/подсказку и перегоняются обратно. **Ускорение через настоящий VisNet ещё не перенесено.** Произвольные контейнеры аддонов пока не поддержаны этим ограниченным native adapter.
- Великое и серебряное деревья, саженцы, древесина/доски и магический камень; фильтры, алхимическая печь, перегонные кубы и меха. Настоящую эссенцию можно собрать фиалами, перелить в банки и сортировать бирками.
- Деревянные, великодревесные и серебродревесные жезлы с железными/золотыми/заряженными таумиевыми наконечниками: ёмкость25/50/100vis, исходная стоимость сборки и сохранение материалов/заряда.
- Первая настоящая инфузия: матрица и пьедесталы, формирование алтаря жезлом, эссенция из банок, симметрия/нестабильность, сохранение процесса и серебродревесный стержень. Остальной каталог инфузии ещё не перенесён.
- Таумиевые меч, кирка, топор, лопата, мотыга и четыре части брони: обычный крафт, исходные характеристики, добыча и ремонт таум-слитками. Зачарование саморемонта и рунический щит пока не перенесены.
- Очки откровения: настоящий крафт/экипировка, зрение узлов без таумометра, текущие аспекты ёмкостей и исходная скидка vis. Неизвестные аспекты остаются скрытыми.
- Три мантии: исходная окраска, стирка, ремонт зачарованной тканью и скидка vis. Базовый Shock расходует vis, поражает дальние цели и учитывает преграды/обычную защиту.
- Базовый Excavation: зелёный луч, исходный прогресс добычи, защищённое разрушение блоков с настоящими дропом/опытом и сохранностью контейнеров. Завершённый отказ защиты тоже расходует vis.
- Базовый Frost: настоящий крафт, выбор черезF, ледяной снаряд с рикошетами и обычным уроном3. Оплачивается каждый выстрел; заморозка блоков, замедление и улучшения в базовый фокус не входят.
- Разрушение обычных узлов даёт исходную эфирную эссенцию; её можно перегнать в auram. Работают самородки таумия, выплавка Salis Mundus и обе стадии изготовления таумиевых наконечников.
- Базовый огненный набалдашник: настоящий рецепт, установка/снятие черезF, поток огня с расходом вис, уроном и поджиганием. Поздние фокусы и улучшения ещё не перенесены.
- Сребролист и огненный жемчуг: природные проходы генерации, добыча, переработка в ртуть/огненный порошок, свечение и частицы.
- Тигель: конверсия котла жезлом, нагрев и вода, растворение настоящих брошенных предметов и первые10 алхимических рецептов. Полученный нитор можно поставить как источник света/нагрева; алюментум работает как топливо и метательное взрывное средство.
- Разливы finite flux, замедление/истощение и штраф к расходу vis. Полная экология заражения/тауматические слизни ещё отсутствуют.
- Базовые модели, исходные текстуры, звуки и русская/английская локализация. Полное визуальное соответствие TC4 ещё не проверено.

Полная генерация мира/типы узлов/каталог рецептов, остальные системы алхимии и инфузии, фокусы, големы, продвинутый транспорт эссенции, мобы, заражение и Внешние Земли остаются в плане. ## Зависимости

Minecraft **1.21.1**, JDK **21**, Gradle wrapper **8.12.1**.

| Загрузчик | Зависимости |
|---|---|
| Fabric | Loader 0.16.14+, Fabric API 0.116.17+1.21.1, Architectury API 13.0.11 |
| NeoForge | NeoForge 21.1.259+, Architectury API 13.0.11 |

Версии зафиксированы в `gradle.properties`. Использовать только новые тестовые миры 1.21.1; импорт миров/данных 1.7.10 и 1.12.2 не реализован.

## Сборка и проверки

Windows PowerShell:

```powershell
./scripts/dev.ps1 -Task validate -JavaHome 'C:\path\to\jdk-21'
./scripts/dev.ps1 -Task gametest -JavaHome 'C:\path\to\jdk-21'
./scripts/dev.ps1 -Task client-smoke -JavaHome 'C:\path\to\jdk-21'
```

Linux/macOS с установленным JDK 21:

```sh
./gradlew --gradle-user-home .gradle21 :common:test :fabric:build
./gradlew --gradle-user-home .gradle21 :fabric:runGameTest
```

Проверка воспроизводимости данных и ресурсов:

```sh
python -B scripts/porting/extract_tc4_definitions.py --check
python -B scripts/porting/convert_assets.py --verify
python -B -m unittest discover -s scripts/porting -p 'test_*.py'
python -B scripts/porting/record_verification.py --check-notices
```

TC4 JSON `source_sha256` использует канонический Java-текст: UTF-8 без BOM, CRLF/CR → LF; политика записана в `source_hash_policy`. Это обеспечивает одинаковые source hashes на Windows и LF checkout, без изменений исходников или игрового поведения. Бинарный original JAR hash в source-lock не нормализуется.

Готовые loader-specific файлы находятся в `fabric/build/libs/` и `neoforge/build/libs/`; выбирать обычный JAR без `dev`, `sources` или `shadow`. `common` JAR отдельно в игру не устанавливать. Диагностика в игре: `/thaumcraft status`, `/thaumcraft aspects`.
