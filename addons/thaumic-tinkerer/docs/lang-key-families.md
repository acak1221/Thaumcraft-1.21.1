## Derived research keys

The native Thaumonomicon reads an entry's name and summary only from `tc.research_name.<KEY>` and `tc.research_text.<KEY>`. They are generated per locale from the untouched `ttresearch.*` keys:

* `tc.research_name.<KEY>` = value of `ttresearch.name.<KEY>`.
* `tc.research_text.<KEY>` = value of `ttresearch.prefix` (or `ttresearch.prefix.kami` for a Kami entry) immediately followed by the value of `ttresearch.lore.<KEY>`, with no separator added, as `TTResearchItem.getText()` builds it. The prefixes keep their own trailing space where a locale has one (`de_de`, `ko_kr`); `en_us` has none.
* `ttresearch.page.<KEY>.<n>` stay verbatim: they are the page translation keys.
* The original adds the prefix only while the config option `tooltipIndicators.enabled` is true (default true, `ConfigHandler.useTootlipIndicators`). The converter assumes the default; the option is the code port's decision.

## Escaped percent signs

A `%` that is not a format specifier (`%s`, `%n$s`, `%d`, `%f`) is written `%%`, which both `Component.translatable` and `String.format` render as one `%`. A raw `%` there would make the 1.21.1 `TranslatableContents` parser fall back to showing the unformatted string. A consumer that reads the raw string through `Language.getOrDefault` shows `%%`.

| Locale | Key | Context |
| --- | --- | --- |
| `en_us` | `ttresearch.page.CAP_ICHOR.0` | `... give you a 30% discount on e...` -> `... give you a 30%% discount on ...` |
| `de_de` | `ttresearch.page.CAP_ICHOR.0` | `...duktion von 20% auf alles geb...` -> `...duktion von 20%% auf alles ge...` |
| `fr_fr` | `ttresearch.page.CAP_ICHOR.0` | `... give you a 30% discount on e...` -> `... give you a 30%% discount on ...` |
| `ko_kr` | `ttresearch.page.CAP_ICHOR.0` | `...드캡은 비스 소모량을 20%까지 줄여줍니다. 이제 필...` -> `...드캡은 비스 소모량을 20%%까지 줄여줍니다. 이제 ...` |
| `ru_ru` | `ttresearch.page.CAP_ICHOR.0` | `...их скидку в 20% на все магиче...` -> `...их скидку в 20%% на все магич...` |
| `zh_cn` | `ttresearch.page.CAP_ICHOR.0` | `...一支能够减免各种魔力消耗20%的杖端.现在你能拿这玩意儿做...` -> `...一支能够减免各种魔力消耗20%%的杖端.现在你能拿这玩意儿...` |
