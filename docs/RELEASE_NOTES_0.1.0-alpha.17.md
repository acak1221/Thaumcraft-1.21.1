# Thaumcraft 4 Reload 0.1.0-alpha.17

This alpha includes the changes since alpha.13:

- Native recipe transfer from the Thaumonomicon and EMI to the appropriate crafting interface.
- Restored crucible aspect HUD and smoother aura-node charging with a wand.
- Six deepslate infused ores with native depth-aware generation, plus modern Minecraft adaptations.
- Gameplay, ownership, crafting, world-boundary and rendering fixes from the repository review; details are in `CODE_REVIEW_REPORT.md`.

Minecraft 1.21.1 and Java 21. The release contains separate Fabric and NeoForge mod jars and their source archives. Install the mod jar for your loader with the dependencies listed in the README. Start a new world.

This remains an alpha. Automated checks and their exact results are attached in `BUILD_INFO.json`; they do not establish a full survival playthrough, client visual parity or remote multiplayer acceptance.
