## 0.1.0-alpha.6

Предварительный **Fabric-релиз для Minecraft 1.21.1** с исправлениями двух волн углублённого ревью. Основные изменения касаются сохранности предметов и VIS, межмировых зеркал, совместимости аддонов, интерфейса жезла и поведения чемпионов.

### Что исправлено

- Пьедестал корректно списывает и передаёт VIS, сохраняет резерв и синхронизирует содержимое. Compound-аспекты преобразуются только при установленном усилителе.
- Liquid Death сохраняет конечный объём при растекании и падении. Захват ведром защищён от повторного входа, отказа удаления источника и изменения руки во время callbacks; предметы возвращаются при отказе.
- Межмировые зеркала проверяют обратную ссылку по реальному измерению. Исправлены привязка, расход предметов и устаревший кэш источников; эссенциальное зеркало получило отдельный предмет, рецепт и запись в Таумономиконе.
- Рецепты аддонов исполняют зарегистрированные callbacks и переопределённые сравнения ингредиентов, учитывают компоненты предметов. Исправлены исследовательский контекст, снимок матрицы в событии крафта и синхронизация списка рецептов Тауматория. Complex-регистрация аспектов по тегу учитывает рецептурную базу каждого предмета.
- Аксессуары повторно синхронизируются при смене измерения. Repair не тратит VIS на неэкипированный парящий ранец в хотбаре.
- HUD жезла показывает активный фокус, данные Trade, перезарядку и цену при Shift; исправлен выбор руки. Trade учитывает дальность взаимодействия игрока. Восстановлены внутренние слои и пульсация четырёх фокусов, раскладка аспектов таумометра, положение знамени и позы брони на зомби/скелетах.
- Претор использует одну сохраняемую и синхронизируемую чемпионскую способность. Устранены повторное применение эффектов и ошибки множителей атрибутов относительно TC4.
- Поверхностные структуры соблюдают ограничения измерений; восстановлены доступные аддонам методы blacklist. Fabric добавляет TC4-лут и в заменённые датапаком таблицы. Tier урн и ящиков сохраняется при выборе и размещении предмета.
- Неудачное создание Окулуса сохраняет данные узла без оплаты. Карта лабиринта сохраняется в стабильном порядке и проходит строгое сравнение полного NBT после загрузки с диска.

### Установка

Нужны **свежий мир Minecraft 1.21.1**, **Java 21** и **Fabric Loader ≥0.16.14**. Отдельно установите:

- **Fabric API** — проверено с `0.116.17+1.21.1`;
- **Architectury API** — проверено с `13.0.11`.

Зависимости не включены в JAR мода. Миграция миров из Minecraft 1.7.10/1.12 не поддерживается.

### Проверка и ограничения

Игровой код проверен на коммите `61c8a3c6`; выпуск alpha.6 меняет номер версии отдельно:

- **2561/2561 JUnit** — без ошибок и пропусков;
- **467/467 обязательных Fabric GameTest** — полный прогон на свежем тестовом мире, с сохранением и штатной остановкой сервера;
- **112/112 Python-проверок** инструментов портирования;
- Fabric build, проверки изоляции тестового кода и ресурсов — пройдены.

Пакет alpha.6 пересобран локально на Java 21: повторно прошли **2561 JUnit** и
**3/3 проверок запуска** с новой версией мода. Сравнение содержимого JAR подтвердило
сохранность игрового кода и ресурсов проверенной сборки; номер версии обновлён.
Полный прогон 467 относится к указанному игровому коммиту и отдельно для смены номера
версии не повторялся.

GitHub Actions для предыдущего push не начал
выполнение из-за платёжных настроек аккаунта; результаты выше получены локально,
а не взяты из незапустившегося CI.

Это альфа-версия, а не заявление о полной готовности порта. NeoForge не собирался и не запускался; относящиеся к нему исправления проверены по исходникам. В этой волне не выполнялись физический GL-клиент, осмотр новых игровых кадров, проверка с двумя клиентами и полное survival-прохождение. Серверные и геометрические тесты не заменяют визуальную приёмку; совместимость со всеми аддонами, датапаками и ресурс-паками не подтверждена.
