## Thaumcraft 4 Reload 0.1.0-alpha.7

The first release under the name **Thaumcraft 4 Reload** and the first with jars for both
**Fabric** and **NeoForge** on Minecraft 1.21.1. It replaces the unpublished alpha.6 draft and
contains everything since alpha.5.

### Highlights

- **NeoForge is supported.** The full GameTest suite runs on NeoForge too; two defects that broke
  every NeoForge client (a mixin crash on joining a world, lost GUIs and entity renderers) and
  several NeoForge-only defects (fluid handlers, Hover Harness mining speed, eldritch block XP,
  Primal Crusher, chunk-edge furnace parts) are fixed.
- **Recipe viewers and Jade.** Arcane, crucible, infusion and enchantment infusion recipes and the
  aspect combinations in EMI and JEI; essentia, machine state and golems in Jade. All optional.
- **Aspects for every item.** The remaining rows of the original aspect table and its ore
  dictionary groups, plus an inference for items that did not exist in 1.7.10 (setting
  `aspect_inference`, on by default). Items without aspects: 808 → 117.
- **Baubles you can actually reach.** Key **B** and a button next to your character in the
  survival and creative inventory; empty slots are labelled; a bauble in your hand is put on with
  a right click.
- **Thaumonomicon.** Search, a completion counter, bookmarks, keyboard navigation, reopening the
  last page.
- **Optional tweaks inspired by TC4Tweaks**: varied loot, earth shock that spares items, infusion
  that keeps enchantments, filled phials that stay in hand, a notification clear button. Each is a
  setting; off restores the original rule.
- **World generation.** Magical Forest and Tainted Land patches now follow the world seed (they
  followed seed 0 in every world, and `/locate` pointed elsewhere). The ethereal bloom grows and
  cleanses taint again; the arcane furnace nozzle works.
- **Rendering fixes checked against the original**: the architect focus overlay, thaumometer
  amounts, the held bone bow, warded runes, primal arrows, the thaumic slime shell, wand rods,
  golem bell markers and more.

### Install

| | Fabric | NeoForge |
|---|---|---|
| Minecraft | 1.21.1 | 1.21.1 |
| Loader | Fabric Loader 0.16.14+ | NeoForge 21.1 (built against 21.1.259) |
| Required | Fabric API, Architectury API 13.0.11+ | Architectury API 13.0.11+ |
| Optional | EMI, JEI, Jade, Mod Menu | EMI, JEI, Jade |

Start a fresh world. Worlds generated by earlier alphas get a seam where new chunks meet old
Magical Forest and Tainted Land patches.

### Checked

2590 JUnit tests, 478/478 GameTest scenarios on Fabric and 466/466 on NeoForge on fresh worlds,
120 Python tests, both builds; the new features were inspected in a real Fabric client. Earlier the same
day, before the Jade, JEI and baubles changes, a dedicated server with two Fabric clients passed
37/37 checks. Not yet checked: a long survival playthrough, NeoForge multiplayer. Known gaps: `docs/audit/KNOWN_DEVIATIONS.md` §7.

## Thaumcraft 4 Reload 0.1.0-alpha.7 (русский)

Первый выпуск под именем **Thaumcraft 4 Reload** и первый с jar для **Fabric** и **NeoForge**
на Minecraft 1.21.1. Заменяет неопубликованный черновик alpha.6 и включает всё, что сделано
после alpha.5.

- **NeoForge поддерживается**: весь набор GameTest идёт и на NeoForge; исправлены два дефекта,
  ломавшие любой клиент NeoForge, и дефекты, проявлявшиеся только на NeoForge.
- **EMI, JEI и Jade** (по желанию): рецепты верстака, тигля, наполнения, сочетания аспектов;
  эссенция, состояние машин и големы в Jade.
- **Аспекты у каждого предмета**: недостающие строки оригинальной таблицы и вывод аспектов для
  предметов, которых не было в 1.7.10. Предметов без аспектов: 808 → 117.
- **Аксессуары**: клавиша **B**, кнопка у персонажа, подписанные слоты, надевание правым кликом.
- **Таумономикон**: поиск, счётчик, закладки, клавиатура, возврат к странице.
- **Улучшения по мотивам TC4Tweaks** — каждое выключается в настройках.
- **Генерация мира**: пятна магического леса и порчи теперь зависят от сида мира; эфирный цветок
  и сопло магической печи снова работают.
- **Исправления отрисовки**, сверенные с оригиналом.

Нужен свежий мир. Проверено: 2590 JUnit, GameTest 478/478 на Fabric и 466/466 на NeoForge на свежих
мирах, 120 Python-тестов, обе сборки; новое осмотрено в клиенте Fabric. Не проверено: долгое
выживание, мультиплеер на NeoForge.
