# Продвинутый голем (ADVANCEDGOLEM) — контракт оригинала, 19.10.2026

Источник: оригинал TC4 4.2.3.5 (локальная декомпиляция CFR вне репозитория). Ссылки `E:` — `EntityGolemBase`,
`ConfigRecipes`/`ConfigResearch` — номера строк декомпиляции.

## Что делает «advanced»

| Эффект | Оригинал |
|---|---|
| Слоты улучшений | массив `upgrades` длиной `материал.upgrades + 1` (E:149, 625); третий одного типа по-прежнему нельзя (E:991) |
| Скорость | `speed *= 1.1f` после множителя Air `1 + 0.15·n` (E:376-383) |
| Радиус | `dmod = 16 + 4·Water`, затем `dmod += max(dmod·0.2f, 2.0f)` (E:460-469) — отсюда же радиусы Harvest/Lumber/Fishing, Guard, маркеры, подбор |
| Скорость атаки | `getAttackSpeed() = 20 − 2` тиков (E:1148) |
| NBT | сущность: `advanced` (boolean); предмет-плейсер: `advanced` (byte 1) |
| Колокольчик | при снятии голема в плейсер **всегда** кладётся `advanced` — и обычным ударом (вместе с ядром, улучшениями, маркерами), и приседая (голый плейсер, ядро/улучшения отдельными предметами, ItemGolemBell:270-275) |
| Плейсер | подсказка `tc.adv` («Advanced»), накладной значок второго прохода рендера (ItemGolemPlacer:68-72, 113) |

## Рецепт и исследование

- Исследование `ADVANCEDGOLEM` (GOLEMANCY, 8/0, сложность 2, Concealed, родители `INFUSION` + все шесть `UPGRADE*`),
  `warp 5` (ConfigResearch:350). В порту запись уже есть в `tc4/research.json` (проверено: warp 5, те же родители).
- Инфузия `AdvancedGolem` (ConfigRecipes:326), исследование `ADVANCEDGOLEM`: **центр — golem placer любой
  «metadata» (Short.MAX_VALUE) и любого NBT**, результат — *копия центра с тегом `advanced = 1`* (форма
  `Object[]{ключ, тег}`, не готовый предмет), нестабильность 3, аспекты `mens 8 + sensus 8 + victus 8`
  (порт: `cognitio`, `sensus`, `victus`), пять компонентов: redstone, glowstone dust, gunpowder, **пустая банка**
  (`blockJar`, damage 0), zombie brain.
- Входной плейсер с уже имеющимся `advanced` снова даёт `advanced` (идемпотентно); ядро, улучшения, маркеры,
  имя и груз входного плейсера сохраняются.

## Решения порта

- Материал в порту — отдельный предмет (`golem_straw` … `golem_thaumium`), поэтому «любая metadata» = тег предметов
  `thaumcraft:golem_placers` из восьми плейсеров.
- Инфузия получает **именованную правку результата** (`result_patch`): результат = копия *фактического центра* с
  применённой правкой; поле `result` рецепта — только образец для книги/подсказки. Первая правка —
  `advanced_golem`; правки очков и масок (`goggles`, `mask`) остаются для следующих групп. Рецепт отвергается, если
  правку нельзя применить к центру.
- `GolemData` получает поле `advanced` (JSON-ключ `advanced`, по умолчанию `false` и тогда опускается — все прежние
  предметы сериализуются как раньше; в сети — бит `0x10` последнего байта рядом с маской Guard, чтобы не менять
  раскладку потока; NBT сущности — `advanced` boolean, предмета — компонент). Ёмкость слотов улучшений =
  `материал + (advanced ? 1 : 0)`; больше — по-прежнему ошибка, не усечение.
- Синхронизируемый флаг `ADVANCED` нужен клиенту только для числа слотов; поведение (скорость, радиус, атака) —
  серверное и выводится из тех же функций `GolemUpgrades`.
- Не переносится в этой группе: накладной значок плейсера «advanced» на модели предмета и вид голема — это
  визуал без возможности проверки в контейнере (**seen = нет**), в подсказке плейсера строка `tc.adv` есть.

## Реализация (Fabric/common, 19.10.2026)

Статус маркеров: **implemented / built / game-tested — да; seen — нет** (клиент, значок плейсера и вид голема не
запускались; NeoForge не трогался).

- `GolemUpgrades`: `slotCount(материал, advanced)`, `speed(…, advanced)` (Air, затем `×1.1f`), `range(water, advanced)`
  (`+ max(range·0.2f, 2.0f)`: 16→19,2; 20→24; 24→28,8), `attackSpeed(advanced)` (20→18); прежние сигнатуры оставлены.
- `GolemData.advanced` (10-й компонент record; совместимый 9-аргументный конструктор): JSON `advanced` (опускается при
  `false`, строго булево), сеть — бит `0x10` последнего байта (низкие 4 бита — маска Guard; любые другие биты — ошибка
  декодера), `withAdvanced`, `equals/hashCode`.
- `EntityGolemBase`: синхронизируемый `ADVANCED`, поле сервера, `isAdvanced()`; число слотов улучшений, скорость
  (атрибут при применении конфигурации/загрузке), `getRange()` и `getAttackSpeed()` берут флаг; NBT `advanced`
  (пишется только при `true`; значение не 0/1 → «неподдерживаемые данные», голем остаётся инертным); обычный удар
  колокольчика кладёт флаг в `GolemData` плейсера, приседающий — голый плейсер с `GolemData.EMPTY.withAdvanced(true)`.
- `ItemGolemPlacer`: ёмкость слотов `материал + 1`, строка подсказки `tc.adv`.
- Инфузия: `InfusionStackRecipe.resultPatch` (JSON `result_patch`, провод — необязательная строка после `input_damage`),
  `InfusionResultPatches` с первой правкой `advanced_golem`; `matches` отвергает центр, к которому правка неприменима;
  `assemble` возвращает копию фактического центра, `getResultItem` — патченный образец для книги.
  Рецепт `data/thaumcraft/recipe/infusion/golem_advanced.json` (центр — любой из восьми плейсеров, пять компонентов,
  банка с `empty_jar`, `cognitio/sensus/victus 8`, нестабильность 3, исследование `ADVANCEDGOLEM`), псевдоним
  страницы книги `AdvancedGolem`, иконка исследования `ag` → плейсер с `advanced`.
- Тесты: `GolemAdvancedTest` (8 чистых JUnit) и GameTest `advancedGolemsGainSlotSpeedRangeAndKeepTheirFlag`
  (`GolemAdvancedRuntimeChecks`: настоящий менеджер рецептов, все 8 материалов, провод и JSON, настоящий игрок и големы,
  настоящий Guard и пауки на 18/19/20/23/24 блоках). Исправлены два устаревших теста: проводной помощник
  `rawRecipeWire` (новый необязательный маркер) и `GolemGuardTargetsTest` (бит 16 больше не «повреждён»).

**Отклонения и пробелы:** значок «advanced» поверх плейсера и вид голема (визуал, seen = нет); полный ритуал на алтаре с
этим рецептом не запускался (общий ритуал — `InfusionRuntimeChecks`, патч проверен через тот же `assemble`);
декоративные бонусы (`G`, `B`, `P`) к скорости/радиусу — следующая группа (декорации); правки инфузии для очков и масок
(`goggles`, `mask`) — отдельно.

**Проверка (чистый контейнер Linux, холодный Gradle-кэш):** `:common:test` 393 JUnit (0 падений/ошибок/пропусков), `:fabric:remapJar` + `:fabric:runGameTest` 153/153, JAR SHA-256 `769b2d4bb0282cac2005a75a5738453c05edf3d51df7c42e951a242505a060c3`. Десять мутаций по одной (`scratchpad/mutate_advanced.py`, вне репозитория): девять сразу ловятся; десятая — отключённая проверка `canApply` в `matches` — не ловилась, пока ингредиент рецепта сам ограничивал центр; после прямого теста с рецептом «центр — поршень, правка — advanced_golem» ловится. Все файлы после каждой мутации восстановлены побайтно.
