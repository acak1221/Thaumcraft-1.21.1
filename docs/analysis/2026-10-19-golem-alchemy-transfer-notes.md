## Separate strict native stock

- Public immutable **`record GolemAspectCargo(Aspect aspect,int amount)`**:0…32; empty requires **null,0**, positive requires canonical `Aspect.getAspect(aspect.getTag()) == aspect`; `EMPTY=(null,0)`. `capacityForMaterial(int)` uses supported EnumGolemType **carry directly**:0/1/2/3/5/6/7 →1/4/8/8/16/32/32, rejecting unsupported/Flesh4. `validateMaterial(int)` rejects over-cap stock; no sqrt/water units or upgrade capacity is invented.
- **save()/parse(CompoundTag)** exact fields **Version:INT1 / Aspect:STRING canonical tag / Amount:INT**; empty string only for empty cargo. Missing/extra fields, wrong numeric types, versions, unknown/noncanonical tags, invalid amounts and typed-zero/positive-null combinations are refused, never clamped/default-empty. save returns a fresh tag; parse never mutates input. Future caller retains original raw payload on rejection.
- **readPlacer(ItemStack)** permits absent or empty CUSTOM_DATA as EMPTY; otherwise only sole **AspectCargo** compound with the exact nested payload. **writeToPlacer(ItemStack)** requires a nonempty stack, edits a copy, validates any old reserved payload before mutation, preserves unrelated keys/components, and sets/removes only AspectCargo; zero removes CUSTOM_DATA itself only if no keys remain. Unknown/malformed reserved data is not overwritten even by EMPTY. Preserved unrelated keys still make strict read/placement refuse; in particular existing water data is **not parsed, changed or erased** by this helper.
- Stock value/serialization is **not ownership/admission authorization**, GolemData, ghost controls, display jar, bucket, filled jar/phial, source reference or death output. Root still owns actual placer/material/core/custom-key checks and registration/recipes/client; runtime owns Entity/AlchemyGoals, actual cargo persistence/normal recall and private live intent. Helpers do not connect or complete those other files.
