## Установка (E:892-900, 868-889)

- Применение предмета на любого голема (без ядра тоже): `addDecoration(символ, стек)`; без приседания.
- Отказ без платежа: символ уже есть; взаимные исключения **H↔F**, **G↔V**, **B↔P**.
- Успех: символ дописывается в конец строки, платится один предмет, звук `cameraclack`, пересчёт `setupGolem`.
- Приседающий колокольчик (разборка) **не возвращает** декорацию (`ItemGolemBell:285-307` не пишет `deco`);
  обычный возврат кладёт `deco` в плейсер; плейсер при установке читает `deco` (ItemGolemPlacer).

## Эффекты

| символ | эффект |
|---|---|
| `H` | максимум здоровья `+5` (E:206, 1000) |
| `F` | период регенерации `×0,66` (E:388) |
| `G` | радиус `+max(10%, 1)`: `dmod += max(dmod·0.1f, 1.0f)` до бонуса advanced (E:419-423) |
| `V` | броня `+1` (E:1049); удар голема помечает цель «недавно ударена игроком» на 100 тиков (E:1068-1071) |
| `B` | скорость `×1,1` (E:329) |
| `P` | скорость `×0,88` (E:330-332); броня `+4` (E:1050-1052), потолок 20 |
| `M` | урон `+2` (E:214-216) |
| `R` | Guard/Butcher получают дальнюю атаку `AIDartAttack` (E:254, 285): перезарядка `30 − 8·Air`, цель дальше 3 блоков, в пределах `0,8·радиус`, стрела-дротик |

Порядок скорости в `getSpeed`: материал ×(`B` 1,1) ×(`P` 0,88) ×(1+0,15·Air) ×(advanced 1,1).

## Решения порта

- Строка символов → набор символов в `GolemData.decoration` (JSON `decoration`, опускается при пустой), сеть — отдельная
  строка, NBT сущности `Decoration` (оригинальный ключ), плейсера — компонент; ключ `deco` оригинала не нужен.
- Предметы регистрируются только для работающих эффектов: `H G B F V P M` — сразу, `R` (дротик) — только вместе с
  `AIDartAttack` и снарядом (отдельная подгруппа), чтобы не появился предмет без эффекта.
- Визуал (модель и накладки на голема, значок плейсера) — клиент, **seen = нет**.
