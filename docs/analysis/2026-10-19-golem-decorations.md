# Декорации голема (ItemGolemDecoration) — контракт оригинала, 19.10.2026

Источник: оригинал TC4 4.2.3.5 (локальная декомпиляция CFR вне репозитория). `E:` — `EntityGolemBase`, `ConfigRecipes`/
`ConfigResearch` — номера строк декомпиляции.

## Предметы и символы

`ItemGolemDecoration`: стек 64, damage 0…7, вкладка TC. Символ декорации (`getDecoChar`) хранится строкой в сущности
(`Decoration`, NBT) и в плейсере (`deco`):

| 0 | Tiny Hat (`golemdecotophat`) | `H` | TINYHAT | ` C `/` G `/`CCC`: чёрная шерсть ×4, золотой слиток; ordo 8 + ignis 8 (ConfigRecipes:252) |

| 4 | Tiny Dart (`golemdecodart`) | `R` | TINYDART | `AIA`/`ADA`/`AIA`: стрелы ×6, железо ×2, раздатчик; aer 4 + ignis 4 (:256) |

у дротика и молота, `tutamen` у забрала и брони).

## Установка (E:892-900, 868-889)

- Применение предмета на любого голема (без ядра тоже): `addDecoration(символ, стек)`; без приседания.
- Отказ без платежа: символ уже есть; взаимные исключения **H↔F**, **G↔V**, **B↔P**.
- Успех: символ дописывается в конец строки, платится один предмет, звук `cameraclack`, пересчёт `setupGolem`.
- Приседающий колокольчик (разборка) **не возвращает** декорацию (`ItemGolemBell:285-307` не пишет `deco`);
  обычный возврат кладёт `deco` в плейсер; плейсер при установке читает `deco` (ItemGolemPlacer).

## Эффекты

| символ | эффект |
|---|---|
| `H` | максимум здоровья `+5` (E:206, 1000) |
| `F` | период регенерации `×0,66` (E:388) |
| `G` | радиус `+max(10%, 1)`: `dmod += max(dmod·0.1f, 1.0f)` до бонуса advanced (E:419-423) |
| `V` | броня `+1` (E:1049); удар голема помечает цель «недавно ударена игроком» на 100 тиков (E:1068-1071) |
| `B` | скорость `×1,1` (E:329) |
| `P` | скорость `×0,88` (E:330-332); броня `+4` (E:1050-1052), потолок 20 |
| `M` | урон `+2` (E:214-216) |
| `R` | Guard/Butcher получают дальнюю атаку `AIDartAttack` (E:254, 285): перезарядка `30 − 8·Air`, цель дальше 3 блоков, в пределах `0,8·радиус`, стрела-дротик |

Порядок скорости в `getSpeed`: материал ×(`B` 1,1) ×(`P` 0,88) ×(1+0,15·Air) ×(advanced 1,1).

## Решения порта

- Строка символов → набор символов в `GolemData.decoration` (JSON `decoration`, опускается при пустой), сеть — отдельная
  строка, NBT сущности `Decoration` (оригинальный ключ), плейсера — компонент; ключ `deco` оригинала не нужен.
- Предметы регистрируются только для работающих эффектов: `H G B F V P M` — сразу, `R` (дротик) — только вместе с
  `AIDartAttack` и снарядом (отдельная подгруппа), чтобы не появился предмет без эффекта.
- Визуал (модель и накладки на голема, значок плейсера) — клиент, **seen = нет**.

## Реализация (Fabric/common, 19.10.2026)

Статус маркеров: **implemented / built / game-tested — да; seen — нет** (модель и накладки на голема, значок плейсера, клиент; NeoForge не трогался).

- `GolemDecorations` — чистые правила (буквы `HGBFVPM`, партнёры H↔F, G↔V, B↔P, `valid`, формулы эффектов); `GolemUpgrades.speed/range/meleeDamage` получили
  перегрузки с декорацией, прежние сигнатуры дают тот же результат побитно.
- `GolemData.decoration` (11-й компонент, совместимый 10-аргументный конструктор): JSON `decoration` (опускается при пустой, строго строка, проверка
  правил установки), сеть — бит `0x20` последнего байта объявляет следом строку (голем без декорации заканчивается тем же байтом, что раньше), `withDecoration`.
- `EntityGolemBase`: синхронизируемая строка `DECORATION`, `getDecoration()`; здоровье `+5`, броня `+1/+4` (потолок 20), скорость, урон `+2`, радиус
  `+max(10 %, 1)` до бонуса advanced, период ремонта `×0,66` (`getRegenDelay()`); удар голема с забралом ставит жертве
  `lastHurtByPlayerTime = 100` (новая запись `thaumcraft.accesswidener`) — убитый враг роняет опыт; NBT `Decoration` (оригинальный ключ, только при непустой;
  недопустимое/не строка — «неподдерживаемые данные», голем инертен); `installDecoration` (ПКМ без приседания, любое ядро, платёж одного предмета кроме творческого,
  звук `cameraclack`, пересчёт атрибутов без лечения нового максимума); новая размещённая из плейсера конфигурация стартует с полным здоровьем.
- Плейсер: перечень аксессуаров тёмно-зелёным в подсказке; колокольчик (обычный удар) сохраняет аксессуары, приседающий — теряет (как в оригинале).
- Предметы `golem_decoration_{tophat,glasses,bowtie,fez,visor,armor,mace}` + модели, семь аркан-рецептов (оригинальные формы и vis), псевдонимы страниц книги
  `Tiny*`, иконки исследований, lang en/ru. Дротик (`R`) и `TinyDart` не регистрируются.
- Тесты: `GolemDecorationsTest` (10 чистых JUnit) и GameTest `golemAccessoriesInstallChangeStatsAndSurviveTheBell` (`GolemDecorationsRuntimeChecks`: семь
  загруженных рецептов, настоящий игрок и големы, три пары партнёров, творческий режим, настоящий Guard и пауки на 16/17/18/21/22 блоках, **настоящий Guard
  с забралом убивает настоящего паука — 5 опыта, без забрала — 0**, настоящий ремонт феской: интервал 50 против 76 тиков, NBT, плейсер, колокольчик, подсказки).
  Исправлены два чужих теста по раскладке байта: `GolemGuardTargetsTest`, `GolemAdvancedTest` (биты 32 и 16 теперь легальны).

**Проверка (чистый контейнер Linux):** `:common:test` 403 JUnit, `:fabric:runGameTest` 154/154, JAR SHA-256 `9668a7c32615cd84daa527a1e80b7ab337889110a45233408994a2774a21fc40`.
**Мутации** (25, по одной, затем побайтное восстановление): 11 чистых правил — все ловятся JUnit; 14 проводок — ловятся GameTest-ом (здоровье, броня, урон, радиус,
запись NBT, платёж, потеря в данных плейсера, ветка установки, обновление атрибутов при установке, подсказка плейсера, исследование рецепта) или JUnit (провод), а две
асинхронные — цикл ремонта без фески («fez 76, plain 76») и удар без пометки («0 experience; a golem with a visor must award it») — только после того, как скрипт
научили читать итог пооперационных потоков (первый прогон показал пустой список из-за формата лога, не из-за пропущенного дефекта).
**Отклонения и пробелы:** визуал (модель, накладки, значок), дротик `R` (нужны `AIDartAttack`, снаряд и рендер; он же завершит оговорки Air/Water в подсказках улучшений),
опыт за убийство забралом — только опыт (`lastHurtByPlayerTime`), без `lastHurtByPlayer`, поэтому «добыча только от игрока» таблиц лута не включается.
