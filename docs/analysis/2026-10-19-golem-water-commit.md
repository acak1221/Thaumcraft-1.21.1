## Exact native boundary

- **Level.setBlock(BlockPos,BlockState,int,int)** checks build height/debug, obtains a chunk, calls **`BlockState LevelChunk.setBlockState(BlockPos,BlockState,boolean isMoving)`**, reads actual resulting state, then runs dirty/client/neighbor/shape/state-change notifications. Three-argument Level.setBlock supplies recursion512. Calling Level.setBlock with flags0 still runs lifecycle/shape/state-change work; it is not a silent commit primitive.
- **LevelChunkSection.setBlockState(int,int,int,BlockState[,boolean])** changes the palette and nonempty/random-block/fluid counts only. Its boolean selects locked versus unchecked palette access, **not deferred world callbacks**. Direct section writes omit four heightmaps, sky-light-source maintenance, light checks/section-status changes, BE lifecycle and chunk dirty state; recreating all that is unnecessary and fragile here.
- **LevelChunk.setBlockState bytecode offsets64–195** writes the section and updates **MOTION_BLOCKING, MOTION_BLOCKING_NO_LEAVES, OCEAN_FLOOR, WORLD_SURFACE**. Offsets196–300 update light-engine section emptiness if needed, update `ChunkSkyLightSources`, and enqueue `checkBlock` when light properties differ. Offsets302–480 invoke old.onRemove, verify the requested block still occupies the section, invoke new.onPlace, and handle BEs. Offsets481–488 set **unsaved=true** and return the actual old state. Do not duplicate its heightmap/light/dirty bookkeeping.
- **Not generally hook-free:** chunk calls both block lifecycle methods before returning. Exact **LiquidBlock WATER** has no onRemove override; inherited **BlockBehaviour.onRemove** only removes a BE when old.hasBlockEntity, false here. **AIR.onPlace** inherits the empty BlockBehaviour body. Neither native body runs neighbors, entity operations, claim events or source refill. `isMoving=false` does **not** suppress lifecycle calls. WATER.onPlace would schedule a fluid tick, but is not the forward WATER→AIR operation.
- The native chunk method itself has no `sendBlockUpdated`, general neighbor/shape dispatch or Fabric/Architectury BEFORE/AFTER dispatch. Native `ThreadedLevelLightEngine.checkBlock/updateSectionStatus` enqueue light tasks before return; this is real internal bookkeeping, not deferred player-block-break authorization or a guarantee of atomic lighting observations. Server block/client-delta/navigation notification belongs to **ServerLevel.sendBlockUpdated**, after the chunk call in Level's wrapper.

## Native post-credit notification tail

Use **F=`Block.UPDATE_ALL_IMMEDIATE`=11**, the literal flags used by **LiquidBlock.pickupBlock** for its native source→AIR removal (without producing/keeping its bucket item). F=NEIGHBORS1|CLIENTS2|IMMEDIATE8; moving64 and KNOWN_SHAPE16 are unset. Level's shape flags are **F & ~(CLIENTS2|SUPPRESS_DROPS32)=9**, recursion **UPDATE_LIMIT512−1=511**. For the no-interference case replay these **public** native calls in this order:

```java
level.setBlocksDirty(pos, old, air);
level.sendBlockUpdated(pos, old, air, 11); // native server gate: full status >= BLOCK_TICKING
level.blockUpdated(pos, old.getBlock());
old.updateIndirectNeighbourShapes(level, pos, 9, 511);
air.updateNeighbourShapes(level, pos, 9, 511);
air.updateIndirectNeighbourShapes(level, pos, 9, 511);
level.onBlockStateChange(pos, old, air);
```

- The public signatures take `(BlockPos,BlockState,BlockState)` for dirty/state-change, plus int flags for sendBlockUpdated; `blockUpdated(BlockPos,Block)`; state shape calls take `(LevelAccessor,BlockPos,int,int)`. **AIR has no analog output**, so Level's optional `updateNeighbourForOutputSignal` branch is absent. Do not call Level.setBlock again with the same AIR expecting its tail: unchanged chunk state returns null and skips notifications.
- `setBlocksDirty` is a native server-base no-op but keep wrapper order. `sendBlockUpdated` marks the real chunk's block delta and invalidates path-type cache; `blockUpdated` runs native neighbors. Shape/neighbor calls let surviving water schedule native fluid ticks/refill; no new water tick at the AIR cell or custom refill loop is needed, and stale scheduled water ticks cannot authorize another cargo credit. `ServerLevel.onBlockStateChange` handles POI differences (none for water/air), not claim AFTER.
- Root dispatches **AFTER with the captured real old water state/BE=null only after credit**, separate from those native calls, then feedback. Re-read actual cell/chunk/worker after each effectful stage/callback. If a callback replaces/refills it, stop acting on stale AIR or overwriting that replacement; fresh native mutations own their own notifications. Post-credit callbacks, failed feedback or death never refund/repeat the source. Any compatibility exception is reported as such, not made into an empty decode or source restoration.
- Loaded-only resolving/preflight does not turn standard neighbor propagation into a sandbox for arbitrary downstream block/addon code. Check the immediate loaded halo and never explicitly force chunks; native propagation still follows normal Minecraft behavior. Runtime Mixins injected into chunk/lifecycle/light calls can add pre-credit effects or events the Level bypass does not reproduce; that is an **explicit addon compatibility boundary**, not universal hook support. No new Mixin is required by the inspected native pair; do not generalize this primitive to other blocks/BEs.
