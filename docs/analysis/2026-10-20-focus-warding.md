# Фокус ограждения (Warding) и сохранённые блоки — TC4-контракт, 20.10.2026

Источники: оригинал TC4 4.2.3.5, CFR вне репозитория: `ItemFocusWarding`, `BlockWarded`, `TileWarded`,
`ConfigRecipes:340`, `ConfigResearch:85`, `WandManager.toggleMisc/getAreaX/getAreaY/getAreaZ/getAreaDim`.
Справочник 1.12 не используется как спецификация.

## Контракт оригинала

- Каждый защищаемый блок стоит **25 terra + 25 ordo + 10 aqua центивис** (0,25 / 0,25 / 0,10 vis),
  с обычной скидкой материала жезла/экипировки/Frugal. Цвет фокуса 16771535, сортировка `BWA`.
  Повторный клик по той же координате и измерению блокируется на 500 мс независимо от игрока.
- Разрешён «обычный сплошной блок» без TileEntity. Его настоящий block id, metadata и свет запоминаются;
  на месте появляется неразрушимая оболочка `blockWarded`, владелец — `playerName.hashCode()`.
  Стоимость уплачивается перед заменой каждого кандидата; последующая неудача не возвращает vis.
- Владелец может тем же фокусом бесплатно вернуть исходный блок. Другой владелец не снимает защиту;
  смена фокуса/игрока не превращает оболочку в обычный выпадающий материал. Содержимое контейнеров не копируется,
  поскольку любые TileEntity изначально исключены.
- `BlockWarded`: hardness −1, старый resistance setter 999 (native resistance 599,4), нет обычного дропа/предмета;
  `onBlockExploded` намеренно пуст, существа/листва не разрушают блок. Исходные текстура/цвет/свет/геометрия
  делегируются запомненному блоку; отдельный рендер добавляет руны/связанные стёкла.
  Делегируются также коллизии, атака, ходьба/падение/контакт существа, частицы, поддержка растений/листвы,
  основание маяка и сила книжных полок. Звук остаётся каменным; `canProvidePower` и слабый/сильный redstone-сигнал
  оригинал **не** делегирует — защищённый redstone block не должен получать новую возможность питания.
- Ранги: Frugal на всех; Architect дополнительно на ранге 2; Enlarge дополнительно на рангах 3–5,
  причём Enlarge требует Architect. Радиус Architect — `3 + Enlarge`; связный обход шести соседей
  внутри ограничивающего объёма, остановка на неподходящем или чужом блоке. При снятии защиты обход проходит
  только через принадлежащие владельцу оболочки, при создании — через подходящие обычные блоки.
- Настройки Architect хранятся в жезле: по умолчанию **каждый радиус равен максимуму**. G увеличивает размер
  выбранного измерения и после максимума сбрасывает в 0; Shift-G выбирает `все / X / Z / Y`.
  На боковых гранях X означает вертикальный радиус, Y глубину, Z вторую ось плоскости.
- Инфузия `FOCUSWARDING` / `FocusWarding`: центр — Nether Star; quicksilver, Earth Shard, quartz, Order Shard
  дважды в указанном порядке; нестабильность 4, `terra25 / tutamen25 / ordo25 / cognitio10`.
  Исследование скрыто до `FOCUSEXCAVATION` и `INFUSION`, исходный переключатель `Config.wardedStone` включён по умолчанию.

## Нативная реализация и адаптации

- `ItemFocusWarding` / `WardingCasts`: настоящий серверный игрок, удерживаемый жезл, его текущий фокус,
  загруженный луч/цель, `mayInteract` и `mayUseItemAt`; каждую замену дополнительно разрешает
  `BlockEvent.PLACE`. После обратных вызовов перепроверяются игрок, рука, весь стек жезла и тот же блок/плитка.
  Вложенная активация во время попытки отклоняется. Сам факт вызова публичного helper не даёт права изменения
  произвольной удалённой координаты: helper сам снимает луч с текущего игрока.
- `ThaumcraftWards` / `BlockWarded` / `TileWarded`: отдельный id `thaumcraft:warded`, нет BlockItem;
  полный исходный **BlockState**, его свет и UUID владельца сохраняются и синхронизируются.
  Источник должен быть сплошным нормальным кубом без block entity/жидкости; копирования инвентаря нет.
  При снятии возвращается тот же BlockState; обновляются соседи и назначается тик исходного блока.
- **Исправление полномочий исходного owner hash:** `AaAa` и `BBBB` имеют один Java hash, хотя это разные допустимые
  имена игроков. UUID различает их и переживает смену имени. Импорта старых миров по-прежнему нет,
  поэтому старые строковые/числовые владельцы не мигрируются автоматически.
- **Защита обычного разрушения:** hardness −1 недостаточна против creative `ServerPlayerGameMode.destroyBlock`.
  `WardedPlayerGameModeMixin` блокирует этот путь для оболочки; снять её может владелец фокусом.
  Это явное укрепление полномочий относительно творческого режима оригинала. Административные команды
  остаются прямыми изменениями мира, как для остальных неразрушимых блоков.
- Оболочка блокирует поршни и сохраняется при `onExplosionHit` независимо от энергии взрыва;
  отсутствующая/нечитаемая настройка не превращается в бесплатный исходный блок: NBT сохраняется в карантине.
- `BlockWarded` делегирует сохранённому состоянию геометрию, заслонение света, native pick-block и исходные
  callbacks атаки/ходьбы/падения/контакта/клиентских частиц. `WardedBehaviour` допускает только настоящий,
  валидный BlockState плитки и запрещает рекурсивный вызов оболочки на той же координате.
- **Исправление снятия защиты исходным callback:** `RedStoneOreBlock.attack/stepOn` пытается заменить блок на
  обычную светящуюся руду. Во время делегированного callback `WardedCallbackMutationMixin` запрещает замену
  именно этой всё ещё действующей оболочки через `Level.setBlock`; эффекты на существа и другие координаты
  сохраняются. Область закрывается через `finally`, включая исключения. Сохранённый исходный блок не меняется;
  обычное снятие защиты владельцем вне callback разрешено.
- Узкие native read-hooks переводят исходные Forge-проверки в реальные современные потребители:
  `EnchantingTableBlock.isValidBookShelf`, `BeaconBlockEntity.updateBase`, `LeavesBlock.updateDistance` и проверки
  почвы `BushBlock`/`CactusBlock`/`SugarCaneBlock`/`MushroomBlock`. В мире остаётся настоящая защищённая оболочка;
  её UUID/плитка не подменяются временным обычным блоком.
- `TileWardedRenderer` рисует настоящий сохранённый BlockState с реальными biome tint/освещением/соседями.
  При Warding-фокусе в основной руке камеры рисуются исходные 47 связанных текстур: маска восьми соседей
  одной UUID, исходные перестановки всех шести граней и таблица `UtilsFX.connectedTextureRefByID` из 256 значений.
  Свои руны пульсируют золотистым цветом с alpha0,5, чужие красным с alpha0,25; внутренние грани оболочек скрыты.
  Native rendering восстанавливает GL-состояние и сохраняет исходное смешивание SRC_ALPHA/ONE.
- `WardedHitParticleMixin` запускает исходный hemisphere-эффект перед ванильным отказом частиц невидимого блока.
  `WardHitParticle` живёт 12–16 тиков, сохраняет ориентацию грани, случайный поворот/смещение и кадры `hemis0..15`.
  Это локальная native `CUSTOM`-частица без регистрации нового сетевого протокола.
- `WandArchitect.Area` — ограниченный immutable data component с persistent и network codecs;
  `WandArchitect` сохраняет исходный порядок и оси связного обхода без рекурсивного stack overflow.
  `WandArchitectNetworking` принимает только факт нажатия G: игрок не присылает радиусы/список блоков;
  сервер читает текущий жезл, Architect-улучшение и состояние приседания.
- 500 мс отображены на десять серверных тиков, с отдельной таблицей координат на мир и очисткой при выгрузке.

## Текущее evidence

**Implemented:** базовая серверная защита/бесплатное снятие, точное сохранение BlockState/UUID/света,
обычное разрушение и взрыв, renderer сохранённого блока, данные/ограниченный обход и серверное управление Architect.
Architect подключён к Warding и Trade. Завершение текущей группы добавляет исходное поведение блока,
native поддержку полок/маяков/почвы/листвы, связанные руны и частицы удара.

**Built / game-tested:** базовый `WardingRuntimeChecks` прошёл в локальном integrated4-прогоне после исправления
native id ингредиента `quick_silver`: два подключённых игрока, стоимость/отказ, NBT/точный BlockState,
принудительно выбранный взрывом блок, поршень/разрушение и девять блоков Architect. Этот прогон ещё имел
два посторонних отказа; успех всего suite на его основании не заявляется. Новые forwarding/overlay/particle
файлы и `WardingBehaviourRuntimeChecks` пока не собирались и не запускались.

**Seen:** нет. **Остаётся проверить:** новый native runtime для полок/маяка/почвы/листвы/защищённого callback,
реальная инфузия/выбор через F, сетевой G/Shift-G, reload мира/чанков, клиентский вид/biome tint/свет/руны/частицы,
моды защиты, NeoForge. Файлы/тесты подготовки не являются визуальной приёмкой.
