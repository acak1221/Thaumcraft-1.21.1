# Void-инструменты и броня — контракт и реализация, 20.10.2026

Источник: оригинал TC4 4.2.3.5 (локальная декомпиляция CFR вне репозитория): `ItemVoidSword`, `ItemVoidPickaxe`, `ItemVoidAxe`, `ItemVoidShovel`, `ItemVoidHoe`, `ItemVoidArmor`, `ThaumcraftApi:38, 43` (материалы `toolMatVoid`, `armorMatVoid`), `ConfigItems:489-506`, `ConfigRecipes:449-457`,
`IWarpingGear`, `WarpEvents.getWarpFromGear (:306)`, `EventHandlerRunic.getFinalWarp (:268)`, lang `item.Item*Void.name`, `enchantment.special.sapless`.

## Что делает оригинал

- **Девять предметов** из Void metal: шлем, кираса, поножи, ботинки, лопата, топор, меч, кирка, мотыга. Рецепты — обычные верстачные (`oreDictRecipe`, `ingotVoid` и `stickWood`): `III/I I`, `I I/III/III`, `III/I I/I I`, `I I/I I`, `I/S/S`, `III/ S / S `, `II/SI/S `, `II/S /S `, `I/I/S`. Исследование `VOIDMETAL` лишь показывает эти рецепты на страницах.
- **Материал инструментов:** уровень добычи 4 (выше алмаза), прочность **150**, скорость **8**, прибавка урона **3**, чарность **10**; редкость «необычный». Урон: меч 4 + 3, кирка 2 + 3, топор 3 + 3, лопата 1 + 3, мотыга без урона (чарность мотыги 5). **Материал брони:** множитель прочности **10**, защита **3 / 7 / 6 / 3**, чарность 10.
- **Самолечение:** раз в 20 тиков носителя (`ticksExisted % 20 == 0`) повреждённый предмет в руках/кармане, принадлежащий живому существу, чинится на 1 (`damageItem(-1)`; у игрока в творческом режиме это ничего не делает). Броня дополнительно чинится в `onArmorTick`, то есть надетая деталь чинится **дважды** в секунду.
- **Иссушение:** меч при ударе накладывает Wither на **3 секунды** (кроме удара игрока по игроку при выключенном PvP); остальные инструменты — Wither на **4 секунды** при ударе игрока по существу (кроме любого игрока-цели при выключенном PvP).
- **Warp:** каждый из девяти предметов — `IWarpingGear` с `getWarp = 1`; сумма — предмет в руке + четыре слота брони (`getWarpFromGear`; баублы не переносятся).
- **Ремонт:** проверка ремонта инструментов называет предмет `itemResource` метаданных **15 — Primal Charm** (а не Void Metal Ingot), броня — слиток (метаданные 16); `toolMatVoid` не задаёт материала для ремонта. Это оригинальная особенность, сохранена.
- Меч показывает золотую строку `enchantment.special.sapless` («Lesser Sapping»).

## Решения порта

- `ThaumcraftEquipment`: `VOID_TIER` (150 / 8 / 3 / 10, добыча как у незерита, ремонт — Primal Charm), `VOID_ARMOR_MATERIAL` (3 / 7 / 6 / 3, чарность 10, ремонт — Void Ingot), девять предметов `void_*`; классы `ItemVoid*` по образцу Thaumium-классов (атрибуты `createAttributes(tier, 4/2/3/1, …)`, мотыга без урона и без износа при ударе).
- `VoidMetal`: самолечение (серверное, творческий режим не чинится) и иссушение (правило PvP меча и остальных инструментов). `ItemVoidArmor` чинит дважды, если деталь надета.
- `thaumcraft.api.IWarpingGear` и `thaumcraft.common.lib.WarpGear.fromGear(player)` — сумма по руке и броне. Последствия варпа (события `WarpEvents`) ещё не портированы (M11): сумма пока только считается и проверена.
- Рецепты (`void_*`, тег `c:ingots/void`), теги ванилы (`swords`, `pickaxes`, `axes`, `shovels`, `hoes`, `head/chest/leg/foot_armor`), иконки оригинала, слои брони `void_layer_1/2` (байтовые копии `void_1.png`/`_2.png`, запись в `THIRD_PARTY_NOTICES.md`), имена en/ru из оригинала, псевдонимы книги `VoidHelm … VoidSword`.
- **Отклонение (родная замена):** оригинальные инструменты (кроме меча) накладывали Wither в `onLeftClickEntity` — до удара, при любом левом щелчке по существу; здесь — в `hurtEnemy`, то есть при ударе, который нанёс урон. Разница видна лишь при ударах, не наносящих урон (неуязвимость цели, перезарядка).
- Не перенесено: Void-мантии тауматурга (`ItemVoidRobeArmor`, группа `ARMORVOIDFORTRESS`), броня «крепость», события варпа, рунический щит.
