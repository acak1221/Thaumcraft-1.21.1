## Cause, guard and change

Native `moveTo(Entity, speed)` requests path accuracy 1; actual runtime bytecode
was inspected with `javap`. Adjacent-cell path arrival can be outside pickup
reach. Request native `createPath(pursued, 0)` instead, keeping ordinary native
movement and all original work/reach/stock checks. No timing or fixture outcome
substitution. The original farming fixture and deadlines are unchanged.

The prior guard tests shared-state integrity, not native AI progress. Add a
registered worker witness to the same verdict guard: watch completed pickup
approaches outside reach, fail on three attempts to the same eligible drop,
reset on cargo progress, close the owning fixture before isolation checks, and
retain full worker state on failures. `.tmp-g21b-guard-red.log` catches the
**unfixed** regression at tick37 with actual distance squared
3.8253791156796213, no resource-leak verdict. A retained JUnit wiring check and
the four-position GameTest protect this distinct failure class.

No foreign polluter or false `canWork` clause is demonstrated; naming one would
contradict the measurements. See `docs/audit/GOLEM_ORDER_FINDINGS.md` for exact
clauses, evidence and limitations.
