user's global `.gradle`, no shared build cache writes). Before **each** Gradle command,
`rm -rf fabric/run-gametest/world` was run.

```
./gradlew :fabric:runGameTest --offline --no-daemon --max-workers=2 \
  -PgameTestFilter=g23BossGolemFight,g23BossWardenFight,g23BossPraetorFight,g23BossGiantFight,g23BossTaintacleFight,g23BossPechFight,g23BossPraetorBar,g23BossDeathPlacement
```

lethal damage, not compilation/source-text tests. Three missing pearl drops share the
stale `eldritch_object` registry ID; the original item metadata 3 is now `primordial_pearl`.
The fourth failure is the praetor's missing inherited boss display contract.

One earlier shell invocation failed before Gradle because `.tmp` did not exist; one
subsequent Gradle invocation compiled but rejected the prefix-only test filter. Neither
is gameplay evidence. The valid baseline used the complete comma-separated test names.

No phase health/cooldown/frenzy state is assigned by the new tests. Stationary positioning,
remote player, no gravity, manually driven native entity ticks and seven-point attributed
damage are declared inputs; these must not be represented as a survival fight or client run.

random champion draw left it alive at the fixture's finite 2400-update limit. This was
not classified as an unkillable-boss defect. The final fixture declares the existing

warden drown/wither immunity, giant heavy-hit enrage/cap, and headless beam charging.
