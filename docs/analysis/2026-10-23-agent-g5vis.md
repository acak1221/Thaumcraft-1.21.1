## Candidate and proof method

The native furnace calls `TileAlembic.addToContainer` (which synchronously notifies comparators), then verifies destination stock before removing source stock. A comparator callback can export the credited unit, causing the late readback check to skip the source debit. The original furnace instead removes the source unit before calling the alembic insertion (`TileAlchemyFurnace:230-231,244-249`).

The added GameTest installs a real native comparator with a one-shot output-signal observer, seeds furnace AIR4 and empty alembic/jar, and advances the actual furnace ticker to its 40-tick transfer phase. The observer attempts extraction into the real jar. It asserts the sum and the individual source debit, not merely a return value. The observer is a test-only comparator BE subclass; neither final production endpoint nor `Level` is replaced.

Two further GameTests exercise real native caps/spending/tapping and `AuraHelper` simulation, primal ordering and partial execution. They distinguish centivis from whole node vis and raw network quanta.
