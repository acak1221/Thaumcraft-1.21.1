## ParticleEngine (partial at entry)

Oracle `thaumcraft/client/fx/ParticleEngine.java:57,138-147` owns four
layer/dimension maps, removes index 0 at size >=2000, then appends. Lines 152-196
tick only the current dimension. Lines 74-92 draw layers in order 0,1,2,3;
0/2 are additive, 1/3 standard alpha. This is implementable, not a vanilla
limitation.

Added `client/fx/ParticleLayers.java` (pure queue rules), `ParticleEngine.java`
(native effect owner), `Tc4Particle.java` (explicit opt-in and original layer),
and `common/mixin/client/Tc4ParticleEngineMixin.java` (vanilla add/tick/render
bridge). Vanilla-owned variants deliberately opt out: oracle
`ClientProxy.java:768-770,866-879,1048-1077` distinguishes bursts/fragments
from managed bore sparkles and essentia trails. Native effect renderers retain
their geometry and atlases. Essentia trails now use the actual layer-1 alpha
blend, not the previously hardcoded additive blend (oracle
`fx/particles/FXEssentiaTrail.java:77-99`).

`ParticleLayersTest`: four pure JUnit tests authored, **not executed**. They
assert original cap 2000, independent four-layer caps/order, dimension retention
and selective ticking, adjacent-death removal and explicit disconnect clearing.

## RenderEventHandler (partial at entry)

Oracle `client/lib/REHWandHandler.java:151-178`: render first, then, only if
`time > lastTime`, step radial scale by .05 and hover scale by .025, with
`lastTime = time + 5`. No catch-up loop. Geometry at :212-259 uses radius
`16 + count*2.5`, ring diameters `2.75/2.55 * radius * scale`, and starts icons
at `-90 * scale` degrees. Implementation and validation follow in the next commit.
