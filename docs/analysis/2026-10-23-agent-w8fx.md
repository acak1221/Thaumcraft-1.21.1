0. No marker is added to lightning bolts, ward hemispheres, breaking fragments,
or other original vanilla-owned effects. A mixed effect class opts its vanilla
variants out with -1. The manager does not kill an evicted particle, matching
the original's reference removal; this matters to callers holding swarm handles.

The inherited native renderers using `GameRenderer.getParticleShader` were
still using vanilla's .1 cutoff, despite old ledger claims. Managed paths now
use the existing registered low-alpha particle shader (for example

`InfusionParticle.java:281`); vanilla-owned infusion variants keep vanilla's
