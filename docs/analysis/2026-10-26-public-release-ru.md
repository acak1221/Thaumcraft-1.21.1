## 3. Что осталось сделать владельцу

1. **Теги.** Прокси этой сессии запрещает push тегов (HTTP 403, политика). Шесть тегов на GitHub
   ещё указывают на старые коммиты с JAR. Сценарий `fix-tags.sh` и `rewritten-tags.bundle`
   (переданы в чате) переводят их на переписанную историю; на имитации удалённого репозитория
   после него ни один тег не достигает JAR. Релизы привязаны к именам тегов и останутся на месте.
2. **Ссылки закрытых PR #1–#3** (`refs/pull/*/head`) GitHub хранит сам, переписать их нельзя; через
   них и по прямым ссылкам на старые коммиты JAR ещё доступны, пока репозиторий приватный это не
   публикация. Полностью убрать их может только поддержка GitHub: форма
   «Remove sensitive data» / обращение в GitHub Support со списком путей и PR.
3. **Влить PR `fabric` → `main`** — тогда посетители увидят новую страницу.
4. **Выпуск 0.1.0-alpha.7.** Заметки — `docs/RELEASE_NOTES_0.1.0-alpha.7.md`, jar для Fabric и
   NeoForge собраны и переданы в чате. Создать выпуск через API из этой сессии нельзя. Черновик
   alpha.6 можно удалить: alpha.7 его заменяет.
5. **CI.** Все запуски с 23.10.2026 завершаются за 3–4 секунды без журналов (HTTP 404) — GitHub
   их не запускает, обычно это исчерпанные минуты Actions или оплата приватного репозитория.
   `actions/checkout@v7` существует, локально всё проходит. У публичного репозитория стандартные
   раннеры бесплатны; проверьте вкладку Actions после открытия.
6. **Открыть репозиторий**: Settings → General → Danger Zone → Change visibility.
