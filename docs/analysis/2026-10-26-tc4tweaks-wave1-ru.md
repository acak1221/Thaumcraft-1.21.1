# TC4Tweaks, волна 1: четыре игровых улучшения как настройки — 26.10.2026

Базис: `defec60` (ветка `fabric`). Запрос пользователя: взять из
[TC4Tweaks](https://github.com/Glease/TC4Tweaks) улучшения удобства и оптимизации.

## Что такое TC4Tweaks и как он использован

TC4Tweaks — мод-компаньон TC4 для 1.7.10: около 70 патчей байткода (ASM) и несколько модулей.
Лицензия AGPL-3.0 с исключением для Forge. Код к порту неприменим: он правит байткод 1.7.10, а
порт написан заново на 1.21.1. Поэтому **код не копировался**. TC4Tweaks прочитан, чтобы узнать,
какие правила TC4 он меняет и какие у него значения по умолчанию. Каждая идея реализована заново
в коде порта и сверена с байткодом оригинального JAR. Источник указан в `THIRD_PARTY_NOTICES.md`.

Каждое улучшение — настройка на новой вкладке «Улучшения» экрана настроек, по умолчанию как в
TC4Tweaks. Выключенная настройка возвращает правило оригинала. Все четыре записаны как принятые
отклонения в `docs/audit/KNOWN_DEVIATIONS.md` §8.

| Группа | Что в TC4Tweaks | В порту |

| | Имена файлов данных игрока, падения рендереров и генерации 1.7.10 | Не относятся к 1.21.1 |
| | Одна и та же зачарованная книга и заряд амулета до перезапуска | **Взято**: `more_randomized_loot` |
| | Земляной удар уничтожает предметы и опыт | **Взято**: `earth_shock_targets` |

| | Наполненный флакон остаётся в руке | **Взято**: `filled_container_to_hand` (флаконы и банки у перегонного куба) |

## Четыре настройки

Оригинальное поведение подтверждено по байткоду JAR 4.2.3.5 (`javap`, вне репозитория).

1. **Разнообразная добыча** (`more_randomized_loot`). Оригинал (`Utils.generateLoot`) один раз
   зачаровывает книгу из общего пула, и до перезапуска сервера все книги из мешков, урн и ящиков
   одинаковые. Амулет вис из добычи заряжался один раз за запуск. Теперь книга зачаровывается при
   каждой выдаче, пул хранит обычную книгу. Амулет получает свой заряд с тем же разбросом, что в
   оригинале: 0–4 вис каждого первичного аспекта.
2. **Земляной удар ранит** (`earth_shock_targets`). Оригинал (`EntityShockOrb`, поле удара) ранит
   любую сущность и уничтожает выпавшие предметы и сферы опыта. По умолчанию — только существа;
   1 — всё, кроме предметов и опыта; 0 — оригинал. Замедление в поле действует на всех.
3. **Инфузия сохраняет чары** (`infusion_keeps_item_data`). Оригинал (`TileInfusionMatrix`)
   берёт результат рецепта как есть, и зачарования и имя центрального предмета теряются. Теперь,
   если центр и результат — броня или инструмент, на результат переносятся все компоненты, которые
   центр меняет, кроме заданных самим рецептом (рецепт главнее). Компоненты, задающие вид
   предмета (прочность, размер стопки и подобные), не переносятся. Перенесённый износ не ломает
   результат. Касается рецептов из данных и простых рецептов аддонов, но не подклассов, которые
   сами вычисляют результат.
4. **Полный флакон остаётся в руке** (`filled_container_to_hand`). Оригинал (`ItemEssence`)
   кладёт наполненный флакон в первый свободный слот. Если наполняется последний пустой флакон в
   руке и для полного нет стопки с местом, полный остаётся в этой руке. То же у перегонного куба
   для последней пустой банки.

  флаконы. Их поведение проверено только сценариями GameTest на сервере.
- `update_scope_ledger.py --check`: нужен приватный oracle. Отметки `ACCEPTED DEVIATION` в
  журнале объёма не добавлены.
