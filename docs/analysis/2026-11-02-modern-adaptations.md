# Следующие адаптации к Minecraft 1.21.1

Read-only обзор по запросу владельца после глубинной кристаллической руды. Перечисленные
ниже возможности пока не реализованы и не являются заявлением о найденных регрессиях TC4.

| Приоритет | Адаптация | Основание в текущем коде |
|---|---|---|
| Высокий | Сканирование Breeze, Bogged, Warden, Allay, Sniffer, Frog, Armadillo | `EntityAspectBindings` выбирает только зарегистрированные строки исходного корпуса; baseline этих новых типов не содержит. Нужны отдельные аспектные таблицы с сохранением приоритета публичных регистраций аддонов |
| Высокий | Големы собирают и пересаживают современные культуры | `GolemCrops` использует старый конечный список; `GolemReplant` уже знает семена свёклы, однако selector жатвы её не выбирает. Факельник, кувшинница и ягоды требуют корректного сбора/пересадки каждого типа |
| Высокий | Магические находки в современных структурах | `FabricThaumcraftLoot.CATEGORIES` охватывает десять старых chest categories; Ancient City, Trial Chambers/vault и archaeology отсутствуют. Нужен согласованный состав/редкость находок |
| Средний | Полные строительные семейства Greatwood/Silverwood | `ThaumcraftNaturals` и `ThaumcraftCosmeticWood` дают основные блоки, ступени/плиты. Двери, люки, заборы, калитки и таблички — новые расширения; стёсывание древесины должно сохранять поведение дерева с узлом |
| Небольшой | Камнерез для магического камня | У brick stairs/slabs только shaped crafting; `minecraft:stonecutting` отсутствует. Можно сохранить способ получения исходного магического камня и добавить обычные строительные выходы |
| Средний | Кузнечные узоры на магической броне | Нет native `trimmable_armor` admission и слоя ArmorTrim на собственных моделях. Один тег не сделает отделку видимой; маски/очки и исходные характеристики должны сохраниться |
| Средний | Современные зачарования через наполнение | Движок `InfusionEnchantmentRecipe` уже работает с native enchantments, но JSON охватывает исходные зачарования. Новые рецепты для трезубца/арбалета/булавы и treasure enchantments потребуют исследований и цены |
| Небольшой | Глубинная киноварь | Киноварь остаётся обычной породой с генерацией Y=0…75. Глубинный янтарь нужно рассматривать отдельно: существующий алгоритм располагает его рядом с поверхностью |

Для новой магии отдельно можно рассмотреть скалк/эхо-осколки как основу датчика вибраций
и Breeze/Wind Charge как основу воздушного фокуса. Это новые механики с отдельным балансом.

Уже поддержанное не нужно объявлять отсутствующим: медные наконечники жезлов, очищение/
трансмутация меди; аспекты аметиста, скалка, древних обломков, Echo Shard, Breeze Rod,
Heavy Core и Trial Keys; часть современных biome tags. Проверены
`data/thaumcraft/port/aspect_inference.json`, `EntityAspectBindings`, `GolemCrops`,
`GolemReplant`, `FabricThaumcraftLoot`, `ThaumcraftCosmeticWood`, native stone recipes и
`ThaumcraftGearModelsClient`. Начать полезнее со сканирования мобов, фермерских големов
и находок в новых структурах: это связывает уже готовые системы с миром 1.21.1.
