# Add-on API — Minecraft 1.21.1

Thaumcraft 4 Reload keeps the public API of Thaumcraft 4.2.3.5 (`thaumcraft.api`) with the types of Minecraft 1.21.1.
This folder is the documentation for add-on authors. [Русская версия](ru/README.md).

## Contracts

1. **Keep units at the call boundary.** `AspectList` does not convert units. Arcane recipe costs and `WandRod`/`StaffRod` capacities are whole vis, as in the original constructors; focus costs, the vis stored in a wand and `VisNetHandler.drainVis` amounts are **centivis** (100 = one vis), see `WandHelper` for each method. Crucible/infusion costs are essentia/aspect units, not centivis or millibuckets. Gear discounts use percentage points; cap modifiers are multipliers. World positions/ranges use blocks, squared distances use blocks². Use timers are game ticks; a focus activation cooldown is milliseconds of real time, as in the original. Read the individual declaration before moving an amount between APIs.
2. **There is no package-wide null or ownership policy.** Some registrations ignore null, some reject it, and some throw `NullPointerException`. Some getters return null, some return an empty list, and many return live mutable references. Follow the member's Javadoc; an undocumented interface is not permission to assume defensive copies or null tolerance. `AspectList.copy()` copies the map, not the mutable `Aspect` identities.
3. **World mutations belong to the owning server thread.** Do not call payment, graph mutation or world-scoped recipe registration from render/network-worker callbacks. Complex object-tag registration requires a loaded server recipe context. Global registration lists are not concurrent addon registries; coordinate initialization with the host. Client rendering/translation queries are not authority to change server state. An interface callback alone does not establish a universal side/thread guarantee.
4. **Retained shape does not mean working gameplay integration.** Numeric enchantment IDs, subtype metadata and arbitrary NBT patches are not native 1.21.1 identities. Follow `@deprecated` replacement guidance; signatures remain available, without a removal date or a binary/source-compatibility promise for 1.7.10 addons. TC6 theorycraft/stages and the generic scannable registry are not wired into TC4 gameplay; native foci use `ItemFocusBasic`, not `IWandFocus`.

See [the contract audit](../audit/API_CONTRACT_DOCS.md) for the exact reviewed subset, unresolved contracts and all 17 migration notes.
