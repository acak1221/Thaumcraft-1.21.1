# API для аддонов — Minecraft 1.21.1

Thaumcraft 4 Reload сохраняет публичный API Thaumcraft 4.2.3.5 (`thaumcraft.api`) с типами Minecraft 1.21.1. Здесь —
документация для авторов аддонов. [English version](../README.md).

## Руководства

Каждый фрагмент Java в руководствах скопирован из [примера аддона](../../../examples/example-addon), который
компилируется при каждой сборке; `python3 scripts/porting/api_docs.py --check` падает, если руководство и пример
разошлись.

1. **[С чего начать](guide/getting-started.md)** — настройка проекта, куда идут регистрации Thaumcraft, единицы,
   ключи перевода, запуск примера.
2. **[Аспекты, теги объектов и сканирование](guide/aspects.md)** — новые аспекты, аспекты предметов и существ, имена
   рудного словаря, обработчики сканирования, кодеки для компонентов данных.
3. **[Исследования](guide/research.md)** — категории, записи и их флаги, страницы, знания игрока (сканы, открытые аспекты), серверные переключатели.
4. **[Рецепты](guide/recipes.md)** — магические рецепты, тигель и наполнение через API и как JSON; варп, бонус
   переплавки, мешки с добычей.
5. **[Жезлы и фокусы](guide/wands-and-foci.md)** — стержни, сердцевины посохов, колпачки, `WandHelper`, фокусы,
   мешочки для фокусов (`IFocusPouch`), `IWandable`, триггеры жезла.
6. **[Блоки, эссенция и вис](guide/essentia-and-vis.md)** — `TileThaumcraft`, хранение и перенос эссенции, сеть вис,
   эффекты.
7. **[Снаряжение и безделушки](guide/gear-and-baubles.md)** — слоты безделушек (надевание из руки и отказ от него,
   `BaublesApi.getWorn`), скидка вис, рунный щит, варп от снаряжения, очки.
8. **[Содержимое Thaumcraft, существа и мир](guide/world-and-content.md)** — поиск предметов и блоков, интерфейсы
   существ, урон, эффекты, генерация мира, рубка деревьев.

## Договорённости

1. **Следите за единицами на границе вызова.** `AspectList` не переводит единицы. Стоимость магических рецептов и
   ёмкость `WandRod`/`StaffRod` — целые вис, как в исходных конструкторах; стоимость фокуса, вис в жезле и количество в
   `VisNetHandler.drainVis` — **сантивис** (100 = один вис), единицы каждого метода `WandHelper` указаны в нём.
   Стоимость тигля и наполнения — единицы эссенции. Скидки снаряжения — процентные пункты, колпачки — множители. Время
   использования — игровые тики, перезарядка фокуса — миллисекунды реального времени, как в оригинале.
2. **Нет общей политики null и владения.** Одни регистрации пропускают null, другие отвергают, третьи бросают
   `NullPointerException`; одни геттеры возвращают null, другие пустой список, многие — живые изменяемые объекты.
   Смотрите Javadoc члена.
3. **Изменения мира — в серверном потоке.** Не вызывайте оплату, изменения сети и регистрацию, зависящую от мира, из
   отрисовки и сетевых потоков. Сложные теги объектов требуют загруженных рецептов сервера. Глобальные списки
   регистраций не потокобезопасны.
4. **Сохранённая сигнатура ≠ работающая механика.** Числовые id чар, метаданные и произвольные NBT не являются
   идентичностями 1.21.1; следуйте указаниям `@deprecated`. Классы в духе TC6 (theorycraft, стадии, общий реестр
   сканирования) не подключены к механикам TC4; фокусы — это `ItemFocusBasic`, не `IWandFocus`.

Подробности — в [аудите договорённостей](../../audit/API_CONTRACT_DOCS.md).
